01 / What is Data Science?

Turn raw data into useful knowledge and better decisions.

🔎

Data Science

An interdisciplinary field that uses statistics, programming, domain knowledge, and analytical methods to understand data and solve problems.

🧹

Data Cleaning

Preparing data by handling missing values, duplicate records, inconsistent formats, and errors before analysis.

💡

Insights & Decisions

Finding meaningful patterns and communicating results so people can make informed decisions.

Why Does It Matter?

  • Discover trends and relationships.
  • Forecast likely outcomes.
  • Personalize services and experiences.
  • Measure performance and improve processes.

Common Data Types

Structured: rows and columns in tables.

Unstructured: images, audio, video, and free text.

Quantitative: numerical measurements.

Categorical: labels or groups.

04 / Machine Learning

Machine Learning helps computers learn patterns from data and use those patterns to make predictions or decisions.

🎯

Supervised Learning

Learns from labelled examples. Common tasks include classification and regression.

Classification Regression
🔍

Unsupervised Learning

Finds patterns or groups in data without target labels. Clustering is one common task.

Clustering Pattern Discovery
🏆

Model Evaluation

Evaluation helps us understand whether a model performs well on data it has not seen before.

Accuracy Precision Recall

Classification vs Regression

Classification: predicts a category, such as spam or not spam.

Regression: predicts a numerical value, such as a house price.

Train and Test

Training data helps the model learn. Test data helps estimate how well the model works on unseen examples.

06 / Student Performance Analysis

A beginner-friendly project idea to explore academic performance using data.

🎓

Project Overview

Analyse how attendance, study hours, and assessment marks relate to student performance.

Goal: Discover patterns that may help students improve their study habits.

🛠️

Tools You Can Use

Python, pandas, Matplotlib, and Google Colab.

Data Cleaning Exploration Visualization

Example Python Workflow

import pandas as pd
import matplotlib.pyplot as plt

data = {
    "Study_Hours": [1, 2, 3, 4, 5],
    "Marks": [45, 55, 65, 78, 90]
}

df = pd.DataFrame(data)

print(df.head())
print(df.describe())

plt.scatter(df["Study_Hours"], df["Marks"])
plt.xlabel("Study Hours")
plt.ylabel("Marks")
plt.title("Study Hours vs Marks")
plt.show()

This is a small illustrative dataset, not real student records. Real analysis should consider other factors and avoid assuming that study hours alone determine marks.
